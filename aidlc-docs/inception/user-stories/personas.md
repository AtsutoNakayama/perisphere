# ペルソナ定義 — perisphere（360°写真 Web ビューワーライブラリ）

- **関連 Issue**: [#21](https://github.com/AtsutoNakayama/perisphere/issues/21)
- **作成日**: 2026-06-17
- **方針**: `plans/story-generation-plan.md`（Q1=B / 3 ペルソナ）
- **前提資料**: `inception/requirements/requirements.md`

本ライブラリのユーザーを 3 種のペルソナに整理する。各ストーリー（`stories.md`）の「As a …」はこのいずれかを主語とする。

---

## P1: 組み込み開発者（Integrator Developer）

| 項目 | 内容 |
|---|---|
| 概要 | React / Next.js アプリに perisphere を組み込み、360°写真の表示機能を自社プロダクトに載せるフロントエンド開発者 |
| 技術背景 | TypeScript / React に習熟。three.js は未経験〜中級。WebGL の低レベル知識は前提にしたくない |
| 目標 | 最小のコードで 360°ビューワーを設置し、props/ref で挙動を制御し、SSR 環境でも壊さず動かす |
| 主な関心 | 導入の容易さ、型安全な API、SSR セーフ、イベントでの状態連携、同梱 UI のカスタマイズ |
| 不満・痛点 | three.js の直接操作、SSR で `window` undefined エラー、リソース解放漏れ（メモリリーク）、ドキュメント不足 |
| 成功の定義 | 数十行で導入でき、主要操作が宣言的 props と命令的 ref の双方で完結する |
| 関連 Epic | E1, E2, E3, E4, E5, E6, E7, E8 |

## P2: エンドユーザー（Viewer / End User）

| 項目 | 内容 |
|---|---|
| 概要 | 組み込み開発者が作った Web ページ上で、同梱 UI を通じて 360°写真を閲覧・操作する一般利用者 |
| 技術背景 | 非技術者を含む。PC / スマートフォン双方。キーボードのみ操作・支援技術利用者を含む |
| 目標 | 直感的に視点を動かし、ズームし、投影モードを切り替え、複数写真を行き来して 360°体験を楽しむ |
| 主な関心 | 操作の滑らかさ、モード切替の見栄え、モバイルのタッチ操作、フルスクリーン、アクセシブルな操作 |
| 不満・痛点 | カクつき、タッチ操作の非対応、キーボードで操作できない、エラー時に画面が固まる |
| 成功の定義 | マウス／タッチ／キーボードのいずれでも主要操作が完結し、60fps 目安で滑らかに動く |
| 関連 Epic | E2, E3, E4, E5, E6, E8 |

## P3: 拡張開発者（Extension Developer / Contributor）

| 項目 | 内容 |
|---|---|
| 概要 | コアの公開拡張点を使い、独自の投影モード・入力フォーマットアダプタ・将来の別フレームワークアダプタ（Vue 等）を実装する開発者。OSS コントリビューターを含む |
| 技術背景 | three.js / WebGL / 投影数学に明るい中〜上級。ライブラリ内部構造を理解して拡張する意欲がある |
| 目標 | コア本体を改修せず、公開インターフェースだけで新しいモード・入力ソース・アダプタを足す |
| 主な関心 | 拡張点の明確さ、同梱機能と同一インターフェースで拡張できること、フレームワーク非依存コアの安定 API |
| 不満・痛点 | 拡張のためにコア改修が必要、内部実装に依存しないと拡張できない、拡張 API のドキュメント欠如 |
| 成功の定義 | 同梱 7 モードと同じ登録 API でカスタムモードを追加でき、入力アダプタ／アダプタ層をコア改修なしに拡張できる |
| 関連 Epic | E1, E2, E5, E7 |
